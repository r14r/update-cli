# What's new in Update CLI 3.0.1

## No-argument workflow

Running `update-cli` without arguments updates the configured repository source first, then asks whether to run `bootstrap` and `install`. Both prompts default to No, and neither action is performed automatically in headless mode.

## Configuration switches

Set the following in `.update-cli/config.json` to suppress optional prompts:

```json
{
  "no parameter": ["update", "no-bootstrap", "no-install"]
}
```

Omit either `no-bootstrap` or `no-install` to enable its prompt. Bare `update-cli update` remains a non-interactive source update, and named `bootstrap`, `build` and `install` commands remain individually invokable.
