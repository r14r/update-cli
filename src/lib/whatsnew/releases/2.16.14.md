# What's new in Update CLI 2.16.14

## Repository init without `--project`

Repository-based initialization no longer requires an explicit project name.

```bash
update-cli init --repository https://github.com/r14r/Boersenfuehrerschein-VideoAnalyzer.git
```

Update CLI derives the project name from the repository basename and removes a trailing `.git`. An explicitly supplied `--project` remains authoritative.

Download/ZIP initialization still requires `--project`.
