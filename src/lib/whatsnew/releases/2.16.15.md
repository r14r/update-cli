# What's new in Update CLI 2.16.15

## Repository sources always use pull mode

If the effective source type is `repository`, Update CLI now always normalizes the effective mode to `pull`.

A stale or contradictory manifest such as:

```yaml
update:
  mode: update
```

can no longer turn a repository source into ZIP update mode. Repository initialization, existing runtime configuration, manifest overrides, CLI source overrides, and migrated configurations all converge on `mode: pull`.
