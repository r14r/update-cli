# What's new in Update CLI 3.0.0

## Explicit lifecycle commands

Update CLI 3.0 separates source synchronization, environment initialization, compilation, and application execution.

- `update-cli update` retrieves and activates an updated repository release without automatically running setup.
- `update-cli bootstrap` initializes the project using its bootstrap workflow (normally `just bootstrap`).
- `update-cli build` compiles the project using its build workflow (normally `just build`).
- `update-cli run` executes the project's manifest-defined run behavior, including CLI entry points and Docker applications.
- `update-cli install` remains available separately for installing the built application.

## Compatibility notes

The default update lifecycle no longer automatically performs the project setup and installation steps. Automation expecting the old combined behavior should explicitly request setup or use the appropriate lifecycle stages.

## Reliability

Existing transactional release activation, recovery, rollback, and project manifest validation remain available.

See `docs/lifecycle.md` for examples and planned lifecycle extensions.
