# What's new in Update CLI 3.0.2

## Semantic version comparison fix

Update CLI uses standard numeric Semantic Versioning for selecting and updating releases. A newer major version, such as 3.0.1, is correctly identified as an upgrade from 2.17.0. Previously, a legacy release-epoch compatibility rule incorrectly classified all 3.x releases as older than 2.x.

The historic pre-reset 3.x numbering cannot coexist unambiguously with the new 3.x series based only on version numbers. This release prioritizes standard Semantic Versioning.
