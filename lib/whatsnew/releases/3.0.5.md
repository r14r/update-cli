# What's new in Update CLI 3.0.5

## Setup is no longer installation

The default `update-cli setup --noui` workflow initializes the project using `just bootstrap`. It no longer triggers `just install`, a complete build, or application deployment. The separate commands remain available:

```bash
update-cli bootstrap
update-cli build
update-cli install
```

## Cleaner test pipeline

- The installation delegation test now uses a small isolated manifest instead of launching the entire production quality gate.
- Compatibility tests match current no-argument defaults and standard SemVer ordering.
- Explicit `update-cli update --setup` no longer conflicts with an automatically inserted `--no-setup`.

Previously repeated Doctor and installation output came from nested integration tests printed when `go test` failed.
