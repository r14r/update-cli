# What's new in Update CLI 2.16.17

## New `whatsnew` command

Show the user-visible changes for the installed Update CLI version:

```bash
update-cli whatsnew
```

Show the changes for a specific documented release:

```bash
update-cli whatsnew --version 2.16.16
```

What's-New content is stored as one Markdown file per release and embedded into the Update CLI binary. The command therefore works after installation without requiring the source repository or network access.
