# Update CLI 3.4.0

## Schema 10 and migration commands

- Runtime configuration (`.update-cli/config.json`) uses schema version 10. Previously supported configurations, including schema 9, can be migrated to version 10.
- `update-cli doctor` checks the schema and migration status without modifying files.
- `update-cli migrate` upgrades the runtime configuration to schema 10, writes a backup of the previous file, and can be safely run again.
- `update-cli doctor --migrate` also migrates legacy project manifests (`update-cli.yaml` / `setup.yaml`) when needed.
- Note: `update-cli.yaml` has its own, independent automation schema, currently schema version 2. Runtime schema 10 must not be used as the manifest schema version.

The runtime schema-10 migration behavior was introduced in 3.3.0; 3.4.0 retains these commands and documents the distinction between the two schemas.
