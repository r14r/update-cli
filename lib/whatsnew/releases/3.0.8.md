# What's new in Update CLI 3.0.8

Interactive `update-cli install` now displays the same four-panel fullscreen interface as update and setup. The project pane contains working directory and the `just install` command, the Content pane tracks installation progress and output, and the Footer reports installation state. Use `--noui` for traditional plain terminal output.

This branch also incorporates the 3.0.5 setup/test fixes pending in PR #13.
