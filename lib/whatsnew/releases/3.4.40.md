# Update CLI 3.4.40

- Remove the public `rollback` command and its version selector.
- Remove the public `restore --snapshot` command and snapshot parameter.
- Remove the associated command handlers, help entries, discovery metadata, Just recipes, and obsolete explicit rollback package.
- Keep internal transaction recovery, which is still required to recover from failed updates. Full removal of transactional snapshots is a separate, unsafe-to-combine architecture change.
