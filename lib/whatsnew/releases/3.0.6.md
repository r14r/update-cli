# What's new in Update CLI 3.0.6

## Copy a complete error report with one confirmation

If an `update-cli update` or `update-cli setup` operation fails, the complete output is saved to `.update-cli/logs/failure-*.log` for configured projects, or the user cache if runtime configuration is absent. An interactive confirmation asks **Copy Error Message to Clipboard?** Selecting Yes copies the entire log in readable text without terminal escape sequences.

The same handling also covers `bootstrap`, `build`, `install`, and the no-argument lifecycle. No prompt appears in headless sessions. Successful commands delete their temporary transcript.

Use `UPDATE_CLI_ERROR_LOG_DIR` to choose a different log directory. Clipboard integration supports macOS (`pbcopy`) and Linux (`wl-copy`, `xclip`, or `xsel`).
